# Pagina serviciu–localitate

URL: `/servicii/[serviciu]/[judet]/[oras]/`.

Ordine: breadcrumbs, H1, introducere 70–120 de cuvinte, firme, servicii disponibile, ghid de alegere, prețuri numai cu dovezi, FAQ, metodologie, surse/data consultării și link de corectură. Serviciile conexe și localitățile apropiate se adaugă numai când există pagini publicate relevante. Nu afișa secțiuni goale.

Firmele trebuie să declare explicit serviciul în localitate; sediul nu constituie dovadă de acoperire. Lista este alfabetică. Include separat ce rămâne de confirmat înainte de programare. Nu deduce tarife, program, certificări sau rezultate.

PoC Brașov: o firmă, introducere despre intervenție la domiciliu și sediu fără adresă confirmată, întrebări despre deplasare și acces. Nu există prețuri validate, servicii conexe sau alte pagini de oraș. `indexStatus: noindex`, `editorialReviewed: false`.
