# Pagina serviciu–localitate

URL: `/servicii/[serviciu]/[judet]/[oras]/`.

Ordine: breadcrumbs, H1, introducere 20–60 de cuvinte, firme, servicii disponibile, ghid de alegere, prețuri numai cu dovezi, FAQ, metodologie, notă compactă despre verificare și legătură către metodologie. Serviciile conexe și localitățile apropiate se adaugă numai când există pagini publicate relevante. Nu afișa secțiuni goale.

Firmele trebuie să declare explicit serviciul în localitate; sediul nu constituie dovadă de acoperire. Lista este alfabetică. Include separat ce rămâne de confirmat înainte de programare. Nu deduce tarife, program, certificări sau rezultate.

Exemplu Brașov: o firmă documentată poate susține o pagină indexabilă după revizuire. Nu presupune că toate localitățile au nevoie de URL separat dacă firmele și informațiile sunt identice.

Indexarea nu cere un număr minim de firme; cere date documentate și utilitate distinctă. Politica actuală: SEO-PLAYBOOK.md.
